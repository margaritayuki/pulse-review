# Как внести вклад

Спасибо за интерес к Pulse Review.

## Перед началом

1. Проверьте существующие issues.
2. Для заметного изменения сначала создайте issue с описанием сценария.
3. Не добавляйте в issue, тесты и скриншоты токены, внутренние адреса, ФИО и
   данные приватных проектов.

## Локальная разработка

```bash
bundle install
cp .env.example .env.local
bundle exec ruby local_server.rb
```

Перед pull request:

```bash
ruby -c local_server.rb
ruby scripts/security_check.rb
```

## Pull request

- делайте одно логическое изменение в одном PR;
- опишите пользовательский сценарий и способ проверки;
- приложите скриншот для изменений интерфейса;
- сохраняйте обратную совместимость файлов `data/*.json`, если меняете настройки;
- обновляйте README при изменении установки или метрик.
