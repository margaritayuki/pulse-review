# Security policy

## Секреты

GitLab token сохраняется локально в `data/connection.json` с правами доступа
только для текущего пользователя. Старые установки могут использовать
`.env.local`. Никогда не добавляйте эти файлы или токены в Git, issues и логи.

Для GitLab используйте токен с минимальным scope `read_api`, ограниченным
сроком действия и доступом только к необходимым проектам.

## Сетевой доступ

По умолчанию сервер привязан к `127.0.0.1` и недоступен из локальной сети. Не
выставляйте его в интернет без аутентификации, TLS и дополнительной проверки
модели угроз.

## Сообщить об уязвимости

Не публикуйте сведения об уязвимости в открытом issue. Используйте GitHub
Private vulnerability reporting в разделе **Security** репозитория.
