# История изменений

Все заметные изменения Pulse Review будут перечисляться в этом файле.
Проект следует [Semantic Versioning](https://semver.org/).

## [0.2.0] — 2026-08-24

### Добавлено

- совместимый backend на Go без внешних runtime-зависимостей;
- тесты правил расчёта отчёта и потокобезопасности;
- отдельные команды установки и запуска Go-версии;
- CI для Go на Windows и macOS;
- релизные бинарники для Windows x64, Mac Apple Silicon и Mac Intel.

### Изменено

- backend полностью переведён с Ruby на Go;
- Ruby и Bundler больше не требуются;
- форматы `.env.local`, `data/*.json` и HTTP API сохранены.

## [0.1.0] — 2026-08-24

Первый публичный релиз.

### Добавлено

- сбор статистики code review из GitLab-групп и проектов;
- команды с отдельными списками участников и правилами подтверждения ревью;
- подсчёт approvals, 👍, комментариев, созданных и открытых MR;
- комментарии, полученные автором к его MR;
- график вовлечённости, фильтры по команде и периоду;
- экспорт таблиц в CSV;
- интерактивная установка и запуск на macOS и Linux;
- нативная установка и запуск на Windows через PowerShell;
- автоматические проверки на Windows и Ubuntu;
- документация по установке, безопасности и участию в разработке.
