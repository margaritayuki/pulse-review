# Architecture Decision Records

ADR фиксирует решение, которое дорого менять или легко потерять при разрастании
контекста. Номер не переиспользуется, принятый ADR не переписывается задним
числом: изменение оформляется новым ADR со ссылкой на заменённый.

Статусы: `proposed`, `accepted`, `superseded`, `rejected`.

Шаблон:

```markdown
# NNNN. Короткое название

Статус: proposed
Дата: YYYY-MM-DD

## Контекст
## Решение
## Альтернативы
## Последствия
## Миграция и проверка
```
