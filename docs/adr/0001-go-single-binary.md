# 0001. Единый Go-бинарник

Статус: accepted  
Дата: 2026-08-29

## Контекст

Pulse Review должен запускаться коллегой без установки языка, package manager
или отдельного web-сервера. Поддерживаемые пользовательские платформы — macOS и
Windows. Локальные настройки и token должны оставаться рядом с приложением.

## Решение

Production-приложение собирается одним Go-бинарником. Он содержит HTTP API и
встроенные файлы `public/*`, слушает loopback и открывается в локальном браузере.
Сборка выполняется с `CGO_ENABLED=0`; альтернативный runtime не используется.

## Альтернативы

- интерпретируемый runtime — отвергнут из-за зависимости от установленной среды;
- отдельный frontend server — отвергнут из-за усложнения установки;
- desktop shell — пока не оправдан объёмом продукта.

## Последствия

- одинаковая серверная логика на macOS и Windows;
- UI должен работать через `http://127.0.0.1`, а не `file://`;
- launcher обязан оставлять процесс запущенным;
- pure-Go зависимости предпочтительнее CGO-зависимостей;
- CI и release обязаны собирать обе платформы.

## Миграция и проверка

CI выполняет `go test`, `go vet`, build и браузерные тесты на macOS и Windows.
Release создаёт macOS arm64/amd64 и Windows amd64 артефакты.
