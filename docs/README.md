# Документация Pulse Review

- [Продуктовые требования](PRODUCT_REQUIREMENTS.md) — согласованное поведение.
- [Системная спецификация](SYSTEM_SPECIFICATION.md) — фактическая архитектура,
  API, расчёты, инварианты и инструкция восстановления контекста.
- [Архитектура объёма работы](WORK_VOLUME_ARCHITECTURE.md) — подробный проект
  развития аналитики; часть разделов описывает целевое, а не текущее состояние.
- [Architecture Decision Records](adr/README.md) — причины принятых технических
  решений и их последствия.

Новое требование сначала фиксируется в продуктовых требованиях. Изменение
технического контракта отражается в системной спецификации. Дорогое или
необратимое решение дополнительно оформляется ADR.
